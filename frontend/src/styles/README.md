# 前端设计系统（学术期刊）

整站按一本**学术期刊**编排：暖白纸面 / 夜读暖黑底、墨色正文、衬线标题；深海军蓝（`--primary`）只用于操作、
链接与当前位置，期刊红（`--mark`）只用于节号、栏目眉题与刊头细线等编辑标记。语义色只表达证据状态：
核验（绿）、缺口（琥珀）、冲突（朱红）。不用毛玻璃、霓虹渐变与满屏粒子。
**界面与文案中不使用 emoji**，图标一律用 `AppIcon`（lucide）。

## 主题骨架

| 位置 | 做法 |
| --- | --- |
| 色彩 | 令牌见 `tokens.css`（亮色「期刊」）/ `tokens-dark.css`（深色「夜读」）；正文与辅助字色对比度 ≥ 4.5:1 |
| 目录与节号 | 每页是期刊的一节，节号、栏目名与一句说明集中在 `lib/pageMeta.ts`；侧栏即目录（带 `§` 节号），顶栏是页眉（`§ 节号 · 栏目` + 卷期号） |
| 页头 | `PageHeader`：`§ 节号 · 栏目` 眉题 → 页名 → 题句（`lib/pageVoice.ts`，引原句时注出处）→ 白话说明，底边细双线 |
| 欢迎页 | 扉页插图是一张文献引用网络：节点依次出现，实心为已核验来源、空心为待核线索，已核验节点汇向「进入」，离场时收拢（`IntroPlate` / `lib/introRender.ts`） |
| 核验刻线 | 运行页与任务记录按子问题画刻线：实线已核验、断口缺证据、虚线检索中，亮暗只由真实数据驱动（`SpectrumStrip` / `prism/spectrum.css`） |
| 动效 | 只保留有含义的过渡（内容进场、换页、网络显影、刻线生长），尊重 `prefers-reduced-motion` |

## 文件

| 文件          | 内容                                                                                                                           |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| `tokens.css`  | 颜色、字号、间距、圆角、阴影等设计令牌；深色主题在 `[data-theme='dark']`                                                       |
| `base.css`    | 重置、基础排版、焦点环、滚动条、`visually-hidden`                                                                              |
| `ui.css`      | 通用组件：`.btn`、`.input`、`.panel`、`.badge`、`.tabs`、`.segmented`、开关、弹窗、空状态、骨架屏、`InfoTip`、`.markdown-body` |
| `shell.css`   | 应用外壳：侧边栏、顶栏、内容区、响应式抽屉                                                                                     |
| `pages/*.css` | 每个页面 / 业务组件一个文件，经 `features.css` 汇总引入                                                                        |
| `print.css`   | 打印版报告（独立令牌，不随主题变化）                                                                                           |

## 约定

- 只用 `tokens.css` 里的变量，不写死颜色；需要新颜色先加令牌。
- 页面标题区用 `.page-header`（h1 + p + `.page-header-actions`）。
- 卡片用 `.panel`，卡片标题用 `.panel-header` + `.panel-title`。
- 字号梯度：12 / 13 / 14 / 15 / 17 / 20 / 24 / 30，正文 14。
- 间距用 4 的倍数（`--space-*`）。
- 不使用 `!important`（`visually-hidden` 等工具类除外）。
- 移动端断点：1100（侧栏收成图标）、760（侧栏变抽屉、单列）。
