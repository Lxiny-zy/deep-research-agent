# 任务通路与数据分析范围验证

更新：2026-10-03。本批为本地工作，未推送、未部署。优先级依用户最新要求调整为：功能/任务通路、产物质量、时间与 token、生命周期健壮性与可靠性。

## 本批打通并验证的路径

`tests/test_scenario_paths.py` 从公开 HTTP 接口上传材料/数据、创建任务，使用实际执行器与 SQLite 保存结果，然后读取任务、事件、工作区、交付登记及每个文件。逐文件核对下载哈希，检查 PDF 文件头和 Office 文件结构。模型和开放检索响应使用固定夹具，不能作为模型准确率、检索召回或生产验收结论。

| 场景 | 策略 | 已验证连接 |
| --- | --- | --- |
| 自动研究 | deep / quick | 创建、检索步骤、执行、结果、四格式下载 |
| 文献综述 | deep / quick / none | 开放检索或上传材料、执行、结果、四格式下载 |
| 同行评审 | none | 上传材料、指定材料处理、意见与四格式下载 |
| 论文精读 | none | 上传材料、完整摘要、四格式下载、绑定任务的两轮流式追问 |
| 数据分析 | none | CSV 上传解析、选表、执行、统计与图表、报告和 XLSX 下载 |
| 幻灯片 | quick / deep / none | 检索或上传材料、结构化内容、PPTX 与 Markdown 下载 |
| 思维导图 | quick / deep / none | 检索或上传材料、节点与引用、HTML/PNG/Markdown 下载 |
| 学术问答 | 无检索 / web / 连续追问 | 会话创建、SSE 完成事件、可选检索、三轮历史持久化及引用 |

七类报告共十四种策略，分别走 inline 与 worker 两种执行模式，共 28 条检查；worker 用真实任务领取与执行，不替换执行方法。学术问答另有两条检查，合计 30 项通过。普通问答不因部署为 worker 模式而错误地依赖研究任务队列；精读追问保持绑定材料，不触发开放检索。

发现的流程阻断：Markdown 论文的 `## Abstract` 后直接接 `## Method`，旧摘要解析只识别 Introduction/关键词等结束标记，误认为摘要不完整，导致精读 PDF/Word/HTML 被拒。本批允许明确的同级或上级 Markdown 标题结束摘要；子标题、围栏代码里的标题及没有结束边界的片段不能伪装完整摘要。相关原文区间及完整接口路径已验证。

## 数据分析：从输入问题约束计算范围

旧统计层自动分析所有数值和分类列。sc73 的 Penguins 输入要求仅分析体重和鳍长、按物种比较，性别/岛屿/年份仅作背景；旧任务却对年份做了三项检验和四项相关分析，且额外生成背景分组图。原自动 pass 不计质量成功。

新增范围选择只返回真实列名，区分测量、比较分组与背景，程序验证列存在、类型、重复角色及编号误用，不生成可执行代码。范围按输入与问题缓存，并冻结进统计快照；恢复、重绘和导出保留同一范围，拒绝换数据或混用不同范围。原始列完整保留，缺失值不补齐。

统计台账与 XLSX 增加分析范围和样本构成，明确按分类列本身计数不等于删除测量缺失后的组内有效 n。导出恢复上下文同步传递这些字段，旧交付上下文仍兼容。交付格式版本为 47。

sc74 在会话/权限切换时被中断，未产生完整交付，不计成功。确认原进程消失后，从同一输入启动 sc75；使用此前授权的阿里云模型配置，只读获取，运行在本地，凭据不落盘。固定代码保存在 `artifacts/sc74-code/`，完整结果在 `artifacts/sc75/dataAnalysis/`。

sc75 模型为 `deepseek-v4.1-flash`，约 582 秒、80,399 tokens，七文件自动检查通过：Markdown、HTML、Word、PDF、XLSX 和两张 PNG。PDF 五页均可提取文字；本批未重新进行逐页视觉打磨。

独立核对使用 sc73 已保存的 CSV/标准库统计基准，不调用应用分析函数生成期望值：

- 原始 344 行、8 列完整保留；体重、鳍长各有效 n=342。
- 仅按 species 对两项测量执行比较；Adelie/Chinstrap/Gentoo 有效 n 分别为 151/68/123，分组均值与独立计算一致。
- 仅一项体重—鳍长相关：有效 n=342，Pearson r=0.8712，与独立值 0.8712017673060112 在显示精度内一致。
- 性别构成有效 n=333、缺失 11；岛屿和年份各 n=344，仅作背景。
- XLSX 包含描述统计、显著性检验、分组统计、相关性、分析范围、样本构成；没有年份或背景列的额外测量检验。
