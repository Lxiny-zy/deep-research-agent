# 工作台配置栏与提交区遮挡修复

状态：本地完成并验证，尚未部署。线上仍为此前发布的 `6d91be7`。

## 问题与修改

- 通用动效规则晚于页面布局加载，将配置栏的 `sticky` 覆盖为 `relative`，却保留顶部偏移，造成面板错位。移除这项覆盖，配置栏的定位与隔离由页面样式负责；窄屏、低高度窗口回到无偏移的普通布局。
- 仅恢复配置栏定位，仍无法避免吸底操作栏在部分滚动位置遮住表单。将开始研究栏放回表单末尾的正常文档流，同时删除固定高度预留与 ResizeObserver。展开配置后需滚动到表单末尾提交。
- 将手机操作栏间距规则放在正确的样式层，修正按钮最小宽度覆盖，允许任务状态和长错误文本换行。
- 提交失败时将错误提示滚动到可见位置；为工作台页面的视口滚动预留顶栏空间，避免聚焦字段被顶栏遮住。
