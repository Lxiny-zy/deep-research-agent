## 页面与问题处理

| 页面或组件 | 发现的问题 | 本轮处理 |
| --- | --- | --- |
| 全局布局、导航 | 手机标题区留白过大，平板按钮拥挤；手机展开菜单沿用旧全宽规则而超屏 | 收紧标题区与内容宽度；平板使用折叠菜单；修正菜单宽度，支持 Esc、外部点击关闭和焦点归还；增加跳到正文入口 |
| 欢迎页、背景 | 装饰抢占正文注意力；暂停偏好和系统减少动画设置不一致；演示离屏仍计时 | 淡化网格与线框，减少粒子并限制绘制频率；增加细线流动信号；统一暂停偏好并持久化；页面隐藏、离屏时停用相关动效；减少动画时保留静态预览 |
| 新建研究 | 标题、输入区和示例卡片在小屏的空间分配不协调 | 调整公共布局、面板、输入区与装饰位置，统一卡片和提示文字的对比度 |
| 历史记录 | 无匹配结果缺少操作入口；请求错误与无记录提示可能同时出现 | 增加清除筛选、重试和按权限展示的创建入口，区分失败与空态 |
| 工作流列表 | 内置模板、空态和自定义列表层次不清；部分请求失败缺少反馈；跳转模板时标题被固定导航遮住 | 调整模板折叠卡片与纸张面板，提供空态入口、模板重试和删除失败提示；为模板定位留出导航高度 |
| 工作流编辑器 | 弹窗可能被导航覆盖；移动页签挤占画布；草稿提示占用过多高度 | 弹窗挂载到页面根部；改用纵向弹性布局；限制提示区高度并允许滚动；修正页签状态与焦点可达性 |
| 角色、模型、检索 | 切换页签后刷新丢失位置；空态不统一；部分输入缺少无障碍名称 | 页签同步 URL；统一空态和错误反馈；补齐输入名称；检查检索卡片、表单和删除反馈 |
| 模型、角色编辑器 | 小屏弹窗遮挡、内部内容不可达；模型弹窗缺少焦点约束和 Esc 关闭 | 修正层级与内部滚动；完善焦点约束、关闭行为；验证底部保存按钮可滚动到达 |
| 设置 | 保存过程中仍可修改字段；必填和数值约束未通过表单生效；保存反馈不清晰 | 使用原生表单校验；保存时禁用字段；固定保存操作区并展示修改状态；重排生效配置摘要 |
| 研究过程、报告 | 结束后仍可能显示等待阶段；短报告高度过大；打印说明对比不足 | 根据终态显示正确文案；收紧面板与统计区；修正标题层级、打印配色和代码块键盘滚动 |
| 引导、登录、错误页 | 引导进度使用了无效的 ARIA 属性组合；错误页视觉与正文脱节 | 使用有进度值的语义角色；统一 404、连接错误和登录弹窗，检查重试、键盘与小屏布局 |
| 研究页断连 | 浏览器复验时发现 SSE 在读取数据库期间被取消，连接清理再次被取消，产生回收告警 | 保护当前仓储读取及会话清理，在读取前后响应断连；已断连时不发起下一次读取；浏览器脚本将连接池异常计为失败 |

样式继续维护在现有职责文件中，没有再增加全局覆盖样式文件。
本轮前端源码改动清单见 [frontend-changes.json](../artifacts/frontend-refresh-20260911/frontend-changes.json)。
