# 指定文献综述与完整输入

更新：2026-10-02。本批为本地开发，未推送、未部署；整体目标仍未完成。

## 已修改的真实问题

- 研究覆盖原先把一篇论文的多个章节 URL 算作多篇；现在与书目采用相同的文献身份规则，并单独记录来源位置数。
- 指定论文导入原先只保留前 12 个片段，契约只保留前 5 个链接。两处静默截断已移除，链接导入保留原有页码/章节定位。
- 文献综述新增“仅指定文献”：完整读取上传材料与明确链接，不进入开放检索，不强求开放综述的文献数量下限；必须有每份材料的可用证据和正文引用。资料库项目不会被这一策略悄悄带入。
- 参考文献列表中的编号不能冒充正文引用。缺失材料、截断材料会阻止正式导出；缺少输入证据只列为材料问题，写作返工只处理可用材料漏引，避免无效重写。
- 三篇真实 PDF 都有题名和作者元数据，但旧链路仅保留文件名。现保留与首页文本相符的题名和作者，传递至附件、来源快照和书目。创建日期不当作发表年份，作者字段不当作学术发表状态。
- 新迁移 `0036` 保存通用文档作者；交付格式版本为 27。SQLite 迁移升级、回滚、重放及模型一致性检查通过，未进行远程迁移。
