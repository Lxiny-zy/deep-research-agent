# 问答生命周期、上下文与交付持久化验收

日期：2026-10-02。本轮在本地继续实现并验证用户与模型的交互、交付文件生成。没有推送、部署、迁移线上数据库或重启线上服务；没有连接实验室服务器。使用用户已授权的阿里云模型配置做本地真实调用，密钥只在进程内存中使用。

## 已实现的行为

- 问题在模型调用前登记稳定 request_id。SQLite/PostgreSQL 事务协调锁和唯一约束防止重复登记；执行租约控制同一会话按顺序生成，后一问执行时才读取前一问的最终回答。并发/重连同一请求复用已有任务，终态失败也不自动重新调用模型。
- 关闭页面只断开流连接，后台仍保存结果。刷新后按请求 ID 查状态；同进程重连重放正文和渠道显式返回的思考内容，先 reset 再恢复，避免重复追加。创建会话的迟到响应不能在离开页面后继续发起模型调用。
- 后端启动恢复尚未开始的 pending 请求，执行前重新检查身份与来源访问权；过期 running 请求标为中断，不假定上游未计费而自动重做。旧租约和已删除会话拒绝迟到结果。消息列表显示等待、生成中及失败状态；未知消耗不伪装为 0。
- 去掉问答历史“最多四轮、每答只取 300 字符”的组装方式。按模型容量保留连续的完整近期轮次，超出时保留初始问题并明确说明遗漏轮次；最新完整轮次也放不下时明确报错。抽取追问证据时也使用对话理解指代，历史答复不充当原文证据。
- 论文材料仍在动态问题和历史前面。补上容量回归发现的错误：结构化 Schema 占用较多空间时，固定预留量可能挤掉长追问，现按扣除规则后的实际剩余容量分别预留材料、对话和修订空间；分配不随问题变化。
- 交付按完整内容摘要登记不可变版本，文件和检查结果持久化；跨进程锁协调同一运行的生成，文件写完后才原子提交索引。下载绑定版本，文件树与下载读取同一索引，重新打开进程后核对大小和 SHA-256，不重新排版。旧版本可在任务继续修改时下载。
- 损坏/缺失的已登记文件返回明确错误，不静默重生成或覆盖；未提交完整的候选不出现在文件树中。新旧存储路径均可读取，短目录前缀发生碰撞时分配不同目录，公开版本号仍为完整 SHA-256。

代码入口：`workbench/qa_requests.py`、`qa_jobs.py`、`qa_context.py`、`qa_api.py`、`delivery_store.py`；前端 `lib/qaRequest.ts`、`QaPage.tsx`、`ReaderPage.tsx`。新增数据库迁移 `0033`，尚未上线。

## 真实模型交互验证

模型为授权配置中的 `deepseek-v4.1-flash`。运行本地 ASGI API 和独立 SQLite，注入真实模型客户端，不对生产 API 提交任务。

1. `qa-requests/acceptance.json`：同时提交同一请求两次，只执行一次模型生成；重开 SQLite engine/store 再提交，返回同一消息，不再调用模型。该次调用 1,405 token。
2. `qa-context/acceptance.json`：再次验证上述并发与重开行为，首次生成 1,388 token。随后插入六轮明确标注的合成历史，在最早一轮长回答的第 300 字符之后放置随机标识，再经真实 API 追问。真实模型准确返回标识，追问消耗 3,862 token；该次验收共两次实际生成。

第二项验证的是历史传输和模型对指代的读取，历史长文本为合成记录，并非六轮真实论文问答；不据此宣称论文解释准确率。没有重新测量本批修改的供应商缓存命中率。既有真实论文核验记录见 `LOCAL_ACCEPTANCE_20261001.md`。

可复现命令：

```powershell
python -X utf8 scripts/accept_qa_requests_live.py --authorized-ssh Aliyun --output artifacts/acceptance/20261002/qa-context --context-check
```

## 交付写入故障与无新增模型调用的复验

真实数据分析运行 `2a37dc83-8dd8-4910-ba83-a9aa47dbbcfd` 完成后，在交付持久化阶段出现 FileNotFoundError。独立复现将栈定位到 Windows 长路径创建：完整版本摘要叠加运行目录使目录达到 284 字符，触发 WinError 3。改为索引记录短物理目录，保持完整内容版本和旧路径兼容。

- 生成 Markdown、HTML、PDF、DOCX、XLSX 和两张统计图，共七个文件，自动检查均通过。
- 重读登记后的文件字节完全一致；另外启动一个独立 Python 进程重复执行渲染入口，完整版本号和七个文件的 SHA-256 均不变。
- 当前版本：`d86b3496cf7807e93958d143db2b7a866092ad42db86e028cff0b1ef042ea09d`。
- 产物：`artifacts/acceptance/20261002/delivery-persistence-recovered/dataAnalysis/`。
