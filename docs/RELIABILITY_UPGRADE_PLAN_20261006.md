## 已确认的缺口

1. ReportActions 的最新态导出与 DeliverablesPanel 固定版本下载并存；文档缓存按 run ID 长期有效，
   跨标签页恢复后存在页面仍是旧稿、下载却为新稿的可能。
2. delivery_store 加载任意文件前校验整包，一个文件损坏会挡住其他完好文件及格式修复入口。
3. 结构化预览的表格数学直接作为字符串显示，单元格引用缺少交互，图形节点仅显示来源表说明。
4. 渲染任务持久化，但前端操作 ID/busy 状态仅在组件内存；断网刷新后丢失操作状态。
5. 渲染执行没有可靠期限，活着却卡住的渲染可一直续租；关闭初始等待虽有限，后续 gather 可无界。
6. QA 恢复扫描固定取最早 200 条 pending；运行中会话的大积压能遮住后续可领取会话。
7. QA 缺少跨会话/用户的接单与队列边界、单轮停止，以及复用中断前准备成果的显式继续。
8. 真实论文简答仍存在数值/专名与所选引文不匹配的降级，需要区分正确拦截和核验误判。
