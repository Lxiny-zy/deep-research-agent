# 长研究任务的子问题保存与主动续跑

更新：2026-10-03。本批为修复真实任务通路失败，尚未推送或部署。

## 实际失败

sc77 经 HTTP 导入两份项目记录、提交资料库研究。实际规划得到八个子问题；在 3,600 秒运行期限到达时，五个子问题已经完成，但整批 `researcher` 步骤尚未提交。结果表及失败 checkpoint 的结果列表均为空，未生成报告或下载文件，不能计为真实场景成功。二十个模型响应记录和原 SQLite 数据库均保留。

原执行方式将 `research_dag` 的全部结果一次性并入候选黑板；外层步骤失败会丢弃候选，因此批次内部已完成的付费工作无法由正常 checkpoint 恢复。

## 按子问题保存与复用

每个完成的子问题将完整 `ResearchResult`（包含原始来源、候选及核验结果）写入本次运行的私有控制目录。继续使用 `ArtifactStore` 的原子写入、大小/配额控制和路径隔离，不将进度记录当作用户交付文件。

记录按运行标识、角色提示词、子问题计划、已有结果、反思轮次、佐证要求及依赖上下文绑定，并保存内容摘要。恢复时校验绑定、摘要和结构，再把来源交回原有快照记录链；只重做尚未完成的子问题。不同运行、上下文或要求不能混用；文件损坏或无法持久化时明确停止，不能静默重读或漏掉问题。

该能力同时接入 legacy 与 planner-driven 执行模式。调度器和工作流的顺序、图、反思、团队路径不再把进度持久化失败或执行租约丢失当作普通失败继续重试、降级或调用后续写作者；未完成的同批任务会取消。

## 修复主动续跑立即失败

第一次恢复副本时，通过 `/api/runs/{id}/resume` 收到 202，但执行器仍使用已过期的绝对截止时间及累计耗时，随即再次报超时。没有发出新的模型请求，不能算恢复成功。

现在显式续跑失败任务时，仓储在同一受保护操作中更新执行时段；inline 和 worker 路径均适用。累计耗时、token 和旧事件保留，用累计耗时起点计算本次时段消耗。自动崩溃接管不续期，仍受原时限约束，避免自动重试无限延长任务。

## 恢复原工作，不重新抽取已完成材料

`scripts/replay_library_progress.py` 在独立数据库副本中离线重放原响应，严格检查每次请求长度及各子问题的完整完成审计。原记录没有提示词哈希，因此本次不能声称进行了原提示词的哈希匹配；今后的采集记录新增输入哈希，重放时若存在会严格检查。

离线重放十九个响应，无新增模型调用，恢复五个完成子问题的 115 条候选，其中 65 条符合报告引用条件，完成审计与原运行一致。原始失败 sc77 不修改、不改判成功。恢复副本位于 `artifacts/sc78-replay4/`。

第二次通过正常 HTTP 续跑接口启动后，运行事件确认五个子问题直接复用，模型从未完成的部分继续。八个子问题均完成并保存，最终报告、下载及资料库问答已结束；日志 `artifacts/sc78-live2.log`。`scripts/verify_library_http.py` 独立检查保存状态、来源归属、文件哈希、可读格式和问答结果，结果为 pass，记录在 `artifacts/sc78-replay4/independent-check.json`。

最终正文 6,388 字符，生成 Markdown、HTML、Word、PDF 四文件，全部下载哈希与登记一致；Office 文件结构可读取，PDF 五页均可提取文字。问答一轮正常完成、回答 1,003 字符，报告和问答的引用全部指向本次导入的两份资料，项目标识一致。

交付登记为 warn，没有 fail 项：实际两份来源低于默认三份来源阈值；建议拆分一处长句；可选概念图语义检查通过，但渲染因关系布局问题抛出 ValueError，未进入下载文件。这些警告保留，不把恢复通过描述为完美交付或首次稳定性通过。

恢复和后续问答新增 33 次模型请求。本次脚本用时约 4,430 秒；累计 token 统计为 1,537,855，其中包含原失败运行保留的 617,212，恢复研究新增 769,937，问答 150,706。它证明通路和恢复可用，不证明时间/token 已优化。

## 尊重明确的无配图要求

真实输入写明“不需要额外图示”，旧写作者却无条件进入配图分支。本批识别常用中英文直接关闭指令，在生成前及复用旧图前跳过可选概念图；同一请求中后续明确要求配图时保留该要求。“不要遗漏图示”等其他否定和引述不视为关闭。其他措辞仍由模型按完整任务要求判断，返回空节点时不生成图。

修订任务也不会重新挂入用户已明确不需要的旧图。该调整作用于可选配套概念图，独立的图表/导图任务仍遵守各自契约。新增十七项回归覆盖这些行为。本次真实运行在补丁前已经进入配图，原图示警告不篡改、不删除。
