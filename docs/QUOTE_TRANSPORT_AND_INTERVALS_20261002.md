## 请求体优化

成品证据核验原先会在每条发现中重复携带相同的完整原文。现只在同一来源、同一引用编号下，对完全相同的长原文使用 `quote_from` 指向本批更早的唯一证据 ID；第一份原文仍完整发送，每条发现的 ID、陈述、来源和其他字段保留。短原文、重复 ID、不同来源或有任何文本差异的原文不作这种处理。

此变化仅作用于模型请求，持久化证据、核验绑定和应用缓存仍使用完整原文。引用子集和修复请求都不会产生悬空引用；材料变化会重新组装请求。

对原 178 条素材的确定性测量：素材 JSON 从 133,989 字符 / 146,962 字节变为 112,424 字符 / 125,284 字节，包含 33 个原文引用。该数字不是整个请求或模型账单的降幅。

真实模型进行了同源小样本对照：两条正确的 MST 数值陈述、一条虚构的 99.99 数值和一个纯表题。完整原文与复用原文两种请求都正确通过前两条、拒绝虚构值并识别表题，均不需协议修复。对照的用户载荷为 3,724 与 2,641 字符，共消耗 9,029 token。记录位于 `artifacts/acceptance/20261002/quote-transport-paired/`。这是有限样本，且连续调用未控制缓存冷热状态，不能外推费用节省或全场景准确率。

## 数值区间修复

旧恢复稿把 `RGB 图像被线性缩放到 [0,1]` 中的区间当成引用 0、1，既导致不存在的引用错误，也会在整理摘录时删掉区间。原论文同样明确写了 `rescaled to [0, 1]`，因此是程序误判。

后端与前端现在识别带明确缩放、归一化、范围或区间语境的数值方括号：保留数据和坐标，不计入书目、不改写为引用链接。数学标记、代码和真实引用继续沿用既有规则；普通引用 `[1,2]` 和无区间语境的错误 `[0]` 不会被掩盖。前端支持区间或前导文字加粗的情况。

回归覆盖了校验、摘录回退、书目重编号、核验单元和实际问答渲染。综述提示还补充保留来源原始精度，优先使用同篇统一对照数据，避免将另一篇的舍入值混入当前来源。交付格式版本为 30。
