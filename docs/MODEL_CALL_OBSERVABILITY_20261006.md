# 实际模型请求记录（N10 首批）

状态：本地工程实现，未发布；仍须候选整合验证。后续整体监控趋势与人工质量判断另计。

## 已接入的链路

- LLM 普通补全、结构化补全与流式补全在实际 SDK 请求入口登记唯一 call_id。
  网络重试、JSON 格式修正及协议兼容重试分别登记，属于同一逻辑操作的请求共享 operation_id。
  来源页面读取、流式片段、渲染和纯解析本身不计为模型请求。
- 模型搜索走相同生命周期，保留其现有用量计入规则；调用预算拒绝的新请求不进入实际尝试计数。
- 记录角色、运行/会话/请求标识、模型、开始/成功/失败/取消、耗时和提供方返回的用量。
  角色使用共享模型的独立浅拷贝绑定，不改变并发角色的归属；客户端和协议能力状态仍共享。
- QA 实时 SSE、实时订阅重放、持久化事件及最终 thoughts 保留请求记录；刷新按 call_id 去重。
  终态记录不会被迟到的开始事件恢复为运行态；未确认结束的历史请求显示“状态未确认”。
- 前端单独呈现“模型请求记录”，与提供方明确返回的思考内容区分；未知用量不显示为零，
  仅按已加载记录计数，不声称未加载历史已经完整统计。
- Prometheus 复用既有 registry，新增按操作种类/结果的请求计数和时长；不把请求 ID、模型名等
  高基数字段设为指标标签。

## 计量与恢复边界

- 元数据不包含提示词、完整私人正文、API 密钥或异常原文；错误只保留类型。
- token 来自提供方实际字段。只返回部分字段时保留部分已知值；未提供价格和计量时不估算费用。
- N8 的输入容量校准在真正收到输入用量时调用，不新增模型请求；角色浅拷贝复用同一档案的校准字典。
  校准只上调保守余量，不称为精确分词，也不将运行时校准因子写入恢复语义指纹。
- QA 恢复环境与实际执行环境均绑定 CONTEXT_POLICY_VERSION，新保护策略不会被旧检查点绕过。
  同一请求的调用上限、主动继续作为新请求及继承已消耗修订次数的约定不变。
