## 真实任务结果

三篇 MST / DGSMP / MST++ 的原完整任务已结束，目录为 `artifacts/acceptance/20261002/provided-review-cold/litReview/`。原注册表为 warn、四文件，但正式正文实际上回退为 178 条证据摘录，缺少综述章节，不能计为任务质量通过。两个完整草稿、模型响应和最终任务均保留；第二稿在 `response-22.json` 和冻结任务的 `unapproved_draft` 中。

最初草稿的问题包括：把两篇的注意力结论推广到三篇、把 CASSI 与 RGB 任务分成三种互不可比输入、将 MST 消融差值关系说反、泛化 DGSMP 的效率优势、混淆 MST++ 的 Valid 与 Test。独立核验发现了大部分错误，第二稿修正了其中多项，但还存在错误归属、缺乏支持的术语展开和错误引用。原核验曾把两段有事实判断的表注当成 non_factual 放行；第二轮加上引用后，又正确拒绝了这些说法。

原模型为 `deepseek-v4.1-flash`，37 次调用均正常 stop，未发生长度截断。提供方返回输入 905,524、输出 575,182、总计 1,480,706 token；其中 270,282 输入 token 命中缓存，464,514 输出 token 为提供方标注的思考用量。上述为该样本的实际用量，不推算渠道计费或承诺其他任务的缓存比例。开放检索调用为 0。

## 本批修复

- 表注与编排说明不能替事实免检。增加中英文常见比较条件断言检查；即使模型把这些断言标作 non_factual，也不能据此通过正文、图示或导图验收。普通表题与开放问题保留；这不是通用事实识别器，其他语义仍需核验。
- 模型遗漏决定或返回不属于当前单元的证据编号时，只重试这些单元一次，保留其余已完成判断并记录恢复结果。原任务有两处此类错误，曾导致整个正文修订提前停止。网络故障仍不触发无效写作返工，恢复失败也不能冒充通过。
- 正文回退成证据摘录时增加任务内容失败门，禁止将其作为正式 PDF/Word/HTML，Markdown 也明确标记失败。确定性生成且与重新计算结果完全一致的统计报告仍可交付，避免误伤数据分析。原失败任务按当前规则重导出到 `provided-review-cold-current/` 后为 fail，仅保留 Markdown。
- 显式二元加减乘除可使用引用中的原始数值计算，程序复核运算结果；舍入使用约等号。结果仅在算式位置获得支持，不能借此证明同段其他事实。未引用运算项、错误结果、除零、冒充精确的舍入值与复杂表达式均不能绕过。指标、单位、方法归属及实验条件仍需语义核验；忠实翻译不能添加派生数字。
- 指定文献综述提示强调按任务/输入分组、逐篇限定共同结论、区别同表比较与跨论文汇总，以及保持 Valid/Test 与单模型/集成归属，不要求搬入所有素材。

核验策略版本为 3，交付格式版本为 28。旧核验记录与交付缓存不能自动冒充新规则下通过。

## PDF 真实版面

用第二稿做独立排版预检查时，PDF 校验拒绝了第 4 页两处文字越界：第一列宽度约 17.74 pt，而 DGSMP 文本约 23.75 pt，MST++ 也无法完整放入。旧列宽主要依据总文字长度分配，长中文叙述挤压了短名称列。

现在先为不可断开的拉丁名称、数字和公式预留宽度，再分配可换行叙述空间；保持既有单元格越界检查。修复后的同一份八页审阅稿通过分页、完整性及越界检查，并实际查看了方法表和条件表。文件在 `provided-review-cold/draft-layout-v2-fixed/`，其中仍含未通过的正文，**不是正式交付或内容验收成功样本**。
