# 文献编号、原文定位与交付投影

本批继续完整项目目标，仅修改本地项目。未推送、未部署、未连接阿里云或实验室服务器，也没有新增项目模型调用。

## 统一书目，保留核验绑定

原报告按片段分配引用编号，一篇论文的 18 处定位会打印为 18 条参考来源。现在保留原 `Report`、定位编号、来源 URL、摘录及哈希，另生成书目目录。正文使用文献编号，内部链接保留原位置或位置组合；例如 `[8][9]` 属于同一论文时显示为一个 `[1]`，链接仍绑定第 8、9 处资料。

目录按正文首次引用顺序排列。公共来源使用已有 DOI 或确定的 URL 规则，上传与资料库文件使用稳定文件/来源标识；不按相同文件名或相似标题合并。保留文章选择参数、重复查询参数的顺序和未知路由片段；arXiv 的不同明确版本保留各自书目，但独立研究数量仍计为同一工作。定位别名不会再要求写作者删除合法引用，重复链接不能提高来源数量。

出版信息只取已有字段。对于给定 PDF，可从匹配原快照哈希的第一页、明确标注的出版物 Citation 块采用现成引用文字；后文的引用格式示例、不完整 DOI 或跨行截断的 DOI 不被当作本篇元数据。无法可靠识别时保留已知文件名/引用信息，不编造作者、年份和刊物。未知版本的本地文件与外部网址不会仅因文字相似而强行合并。

## 页面与各类导出

- 研究页、精读报告页和打印稿使用同一目录。点击正文引用仍按原位置筛选证据；组合引用只显示其所含位置，书目条目可查看该文献的全部已登记位置。目录与正文、URL 映射不符时不用过期目录改写编号。
- 离线 HTML 用本地片段目标展示相应摘录；不增加脚本或外链资源。所有原文内容转义，完整摘录保留。长引文超过短上下文窗口时，页面和打印稿展示完整引文。
- Markdown、HTML、DOCX、PDF、结构化报告、表格导出、BibTeX、幻灯片和导图保持文献编号对应。核验用的原始结构不被改写；导图另有显示编号，原节点定位和核验记录不变。
- 幻灯片的完整参考文献按文字容量分页；单条过长时续页，保持原编号及完整文字。没有把作者/刊物信息静默截掉来适应旧的“每页 14 条”。

## 附录边界与内容完整性

梳理引用时发现，旧的参考文献移除逻辑会把其后的附录、图表也截掉。前后端现在只移除参考文献这一节，保留代码中的标题字样和后续附录；附录继续进入数值与支持关系核验。旧正文检查记录不能自动授权后来追加的附录。

共享表格对象也只投影一次，避免同一单元格在正文和分节中出现时被重复重编号；数值、协议脚注与原始位置记录保持不变。
