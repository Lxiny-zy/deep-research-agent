## 3. 验收标准

### 3.1 所有场景共用的最终质量门

- 结论能回到已读取的原文、数据或用户材料，引用编号、具体依据和来源文件一致；关键主张无依据时
  明确说明，不补写成事实。
- 用户要求的主题、章节、比较对象、数据范围和交付格式都有覆盖；材料缺失与模型遗漏要区分。
- 正文、表格、图、公式、书目和导出文件使用同一份定稿快照；承诺的 PDF、Word、HTML、PPTX、XLSX
  等格式可打开且内容一致。
- 表格数据由代码从已核验的发现渲染，模型只写叙述；区分原始缺失、未读取、读取失败及未找到依据，
  只有经相应范围核对、有依据时才标记“原文未报告”。
- 确定性检查与模型复核都通过；涉及统计、数值、公式、实验条件和比较关系时，执行专门的一致性校验。
- 失败后恢复不重复已成功的昂贵步骤，不丢失已核验证据、用户配置、输入范围或历史上下文。

### 3.2 各场景要求

| 场景 | 代表输入 | 必须交付 | 质量通过标准 |
| --- | --- | --- | --- |
| 自动研究与资料库研究 | 范围明确的研究问题；指定资料库 | 实际检索和来源读取、支持结论的证据、回答问题的报告 | 新问题首次运行形成完整报告；每项核心结论有充分来源；检索或读取失败明确暴露；恢复后不重复已完成子问题 |
| 文献综述 | 指定多篇文献；另测开放检索 | 跨文献主题综合、比较条件、结论与局限，不能用证据摘录清单代替 | 主题覆盖与用户范围一致；主要观点有多篇文献支撑；冲突结论分别呈现；公式、行内引用和书目可用 |
| 论文精读 | 一篇未用于修复的完整论文 | 完整摘要处理、核心方法、关键结果与适用条件、有效原文引用 | 方法、实验设置、主要结果和适用边界都能定位到原文；不把局部片段写成全文结论 |
| 学术问答与精读追问 | 同一会话多轮，含指代、比较和新问题 | 正确保留上下文，正文和思考内容持续呈现，复用已有材料，引用能定位 | 连续多轮上下文正确；新增读取范围可解释；回答简洁，每项引用可定位；无依据时拒答 |
| 同行评审 | 一篇完整论文和明确的评价维度 | 与原文对应的贡献、优缺点和可执行修改建议，评分理由一致 | 贡献、优点、缺点、评分和建议彼此一致；每项事实性批评能回到论文；区分关键缺陷、一般问题和表达建议 |
| 数据分析 | 有说明的真实或公开数据，含缺失或异常 | 与数据相符的方法、可复核的统计、图表和解释，可打开的数据与报告文件 | 统计量可独立复算；总体与分组口径不混淆；方法满足数据前提；XLSX 保留原始范围、样本构成和未分析字段 |
| 汇报幻灯片 | 已有材料、目标听众、汇报时长 | 可打开的 PPTX、合理的内容密度、准确图表和讲稿备注 | 每页承担明确的叙事功能；关键图表与原数据一致；讲稿能支撑目标时长 |
| 思维导图 | 多份材料和指定主题 | 可交互、可导出的文件，正确的概念层级与关系 | 表达关系而非堆积事实；节点无明显重复；标签可读；HTML、PNG、Markdown 一致且可导航 |
| 来源阅读与 PDF 定位 | 回答或报告中的引用 | 选中依据后在原文中定位 | 选中具体依据前不显示旧定位；唯一完整引文准确定位；不能可靠定位时明确失败，不猜测 |

### 3.3 计数口径

- 质量矩阵记录输入、代码版本、首次结果、恢复结果、可打开的产物和剩余问题；恢复成功不覆盖首次失败。
- 只有经产品路径（HTTP API 或界面）完成、按新完成契约进入 done、并通过独立复核的样本，才算该场景可用。
- 优先级按影响排序：无法提交、执行或取回结果 → 上下文错误 → 重要事实错误 → 必要交付缺失 → 显示问题。
- 汇报进度时说明哪些任务实测可用、哪些失败、下一步解除什么阻断；不以新增检查、测试或文档的数量作为进度。

### 13.1 目标、范围与依赖

目标是让各类产物更准确、更易读、更容易复核，并让用户理解任务进度与限制。

2. **N0.2 复用覆盖和核验记录**：将已有“要求项—正文/图表位置—来源—核验状态”关联用于页面查看与导出说明；

3. **N0.3 形成可复现问题包**：基于用户提供的任务和材料，收集必要的版本、问题片段、状态和已授权材料标识；

4. **验收**：同一问题能唯一回到相应版本与原文位置；修改文档后旧记录不会被错误关联到新产物。

### 13.3 七类任务的具体改进

#### N1 课题调研：让覆盖、比较和结论边界可复核（M）

- **N1.1 问题覆盖**：在已有任务要求及阅读范围说明上，呈现已回答的子问题、未解决项、仅摘要来源和全文读取失败；
  说明来源覆盖，不用来源数量冒充证据充分度。
- **N1.2 比较取证**：选证时一起保留比较对象、数据集、训练/测试条件、指标方向和适用范围。
  优先补齐核验指出缺失的具体锚点；修订限定在受影响单元，沿用现有修订上限和阶段缓存。
- **N1.3 检索诊断**：复用相关性筛选、同文去重和来源读取记录，按子问题解释覆盖不足。
  对无法获得全文的来源保持范围说明，不因此生成针对全文的确定结论。
- **工程验收**：用户每个明确要求都有正文位置或缺口说明；条件遗漏、比较反转、模态夸大等反例仍被拦截；
  同一证据不重复计算为独立支持，不同版本的新增或修正结果保留来源身份、条件和引用；
  修订不改无关已核验内容，导出与页面说明一致。
- **人工验收**：结论是否真正回答问题、来源是否覆盖主要观点、优势和局限是否有条件；报告与后续追问分别记录结果。

#### N2 文献综述：从逐篇摘要推进到有条件的综合（M）

- **N2.1 比较表口径**：扩充现有结构化表格中的方法机制、实验条件、训练/测试用途、指标和不可直接比较原因；
  每个事实单元格对应证据，不把缺失值、读取失败和“论文未报告”混为一谈。
- **N2.2 否定结论取证**：论文内部“未给出”回查对应全文，保留找到的互补片段，不以短摘录缺失推断全文缺失。
  领域研究空白须限定检索日期、语料与检索范围；证据不足时只说明“在本次检索范围内未发现”，
  不能用单篇全文证明整个领域不存在相关研究。
- **N2.3 综合结构**：按共同发现、差异、可能原因、不能比较的条件组织内容；每个综合结论关联相关论文，
  保留冲突研究及不确定性，避免用逐篇复述替代用户要求的比较。
- **N2.4 长表与书目**：复用数学和导出结构改善长比较表、重复表头、行内公式及书目分页；不为排版删减必要列。
- **工程验收**：指定论文和点名维度不遗漏；训练尺寸/输入尺寸混用、原文已给参数却声称未给出的反例被检出；
  HTML、PDF、Word 的表格、公式和引用对应同一快照，实际渲染无裁切或裸 TeX。
- **人工验收**：综合结论是否成立、比较是否公平、研究空白是否言之有据；指定文献与开放检索分开判断。

#### N3 同行评审：意见可执行，严重度和评分有解释（M）

- **N3.1 阅读覆盖**：把已有章节覆盖与材料限制呈现给用户；方法材料不足时保留限制，不生成貌似完整的评审结论。
- **N3.2 意见结构**：复用现有意见 ID，统一呈现问题、原文位置、依据、严重度和可执行建议；
  同一缺陷的重复表达归组，但不删除不同证据和条件。
- **N3.3 评分解释**：展示影响评分的关键意见与一般表达建议，保留矛盾检查、严重度和评分约束；
  不允许通过删意见、改措辞或降级严重度绕过检查。
- **工程验收**：网页、冻结 JSON 和导出逐条一致；同维度矛盾被拦截，不同维度合理优缺点可并存；
  材料不足、重复引句与方法子章节均有明确处理，局部修订保持意见来源和身份。
- **人工验收**：批评是否真实、是否抓住重要方法问题、建议能否执行、严重度及评分是否合理。
  这些判断以用户逐条评价为准，不由结构化字段齐全替代。

#### N4 论文精读：完整解释公式、图表和跨页证据（M）

- **N4.1 按关注点组织**：将方法、关键公式、实验条件、局限、可借鉴设计映射到用户实际要求；
  复用摘要与点名内容门，不强迫每篇论文填满无关章节。
- **N4.2 公式与图表说明**：保留符号定义、系数、正负号、图号/子图、坐标轴与比较条件；
  结合已有科学核验呈现解释范围，不把一张子图的结论扩大到整图或整篇论文。
- **N4.3 跨页证据阅读**：复用现有定位器，让一条解释可以连续查看多段、多页依据；
  对重复句和多候选给出可辨别的上下文，定位不足明确提示，不伪造精确定位。
- **N4.4 持续追问**：与 N8 联调论文绑定、用户纠正、压缩后指代及刷新恢复；状态说明来自实际执行事件。
- **工程验收**：倒数系数、正负号、缺少定义、子图范围误用等反例被拦截；跨页候选、版本变化、手机定位可操作；
  各格式保持同一公式含义和证据范围，纸面解释与追问不错误继承旧结论。
- **人工验收**：用户能否据此解释论文方法、实验和限制，且能回到原文验证；新论文和长追问单独登记。

#### N5 数据分析：先明确设计，再改进解释与可复算交付（M）

- **N5.1 分析范围摘要**：复用 analysis_scope、合并预览和输入说明，集中展示分析单位、变量角色、分组、
  配对依据、排除记录及缺失处理；修改范围使旧预览失效，原值与异常提示继续保留。
- **N5.2 重复观测边界**：维持已支持的独立样本和明确两列配对能力；长表先检查实体标识、条件/时间与重复键。
  两条件完整配对长表转宽表可单独实现适配，但必须显式给定匹配规则、报告未配对对象并验证单位。
  多时点、嵌套、聚类和混合设计本批仍不承诺推断，只给描述统计及限制说明。
- **N5.3 解释一致性**：在已有统计台账和前提检查上，核对效应方向、区间、总体/组内差异、
  “不显著不等于相同”“相关不等于因果”，避免用增加检验种类代替设计正确性。
- **N5.4 可复算文件**：报告、图表和 XLSX 共用冻结台账中的变量名、单位、样本量、方法和策略版本；
  清楚区分原数据、处理记录与结果，重导出不重新分析。
- **工程验收**：核心统计值独立复算；交换组名、反转比较、误用总体相关和因果夸大反例被检出；
  重复键、含混配对和单位冲突阻断对应推断；各格式数值、样本构成、来源哈希一致。
- **人工验收**：用户能回答“分析了谁、哪些字段、排除了什么”，可从 XLSX 找到某项报告结论的依据；
  支持内设计与不支持设计都必须给出正确行为，而不是所有输入都强行生成推断。

#### N6 幻灯片：先修备注与分页，再补可编辑图文（L，承接 Q2）

- **N6.1 质量门修正（Q2.1/Q2.2）**：分页前检查每页密度及总页数预算；区分原始页与续页。
  “无备注”等占位不算有效讲稿，续页不能复制整段备注。保留原始 deck 供检查与修订。
- **N6.2 时长与叙事（Q2.3）**：承接听众、时长、目标页数，按背景、问题、方法、证据、结论分配页面与讲稿；
  语速与估算时长明确为可调整假设，不以固定字数证明能支撑实际汇报。
- **N6.3 图表与素材（Q2.4）**：复用已核验表格/图形数据，先支持原生表格及约定范围内的柱状、折线图，
  验证后再扩展其他图型。论文示意图、实验图片和未支持图形作为图片嵌入，保留来源、图号和说明；
  标明其仅能移动/缩放，不宣称可编辑底层数据。不得由截图猜测数值重绘，缺来源的数据不进入结果图表。
- **N6.4 布局与公式（Q2.5）**：继续使用 OMML 公式，统一计算文本框、公式、图表、图片和备注布局；
  增加比较页、方法图页、结果图页等必要版式，处理续页衔接，避免模板装饰挤压内容。
- **工程验收**：空备注、密稿大幅膨胀、重复讲稿等固定反例有效；原生图表能修改数据并更新显示；
  PPTX、Markdown 与冻结证据的关键数字一致，分页不漏内容，公式对象仍可编辑。
  有 Office/WPS/LibreOffice 渲染环境时检查真实页面；缺少环境标明“未完成视觉验收”，不能只解包 XML 就宣布排版通过。
- **人工验收**：用户在常用 PowerPoint/WPS 打开、编辑文本/公式/原生图表并按目标时长试讲；
  检查投影可读性、缺字、空页、重叠、讲稿重复及叙事节奏。兼容性不由文件能打开单独证明。
- **依赖与风险**：先固定 slide/figure schema 和导出能力标记，再实现渲染；新增转图服务需单独核验内存与期限，
  不直接放入当前 1 GiB 生产容器。素材读取范围、图像质量和使用限制随来源保留。

#### N7 思维导图：短标签、完整说明和可读的大图导出（M）

- **N7.1 标签与说明（承接 Q3.3）**：使用短标签加可选详细说明；长度是软预算，
  数字、条件、引用及完整含义在展开内容和 Markdown 中保留，不为缩短标签改变科学结论。
- **N7.2 总览与分支图（承接 Q3.4）**：增加总览及分支 PNG；字号或长宽比超过可读范围时提供分支图，
  不简单将长图缩成不可读图片。跨分支关系在拆图后保留方向、目标标记和关联索引。
- **N7.3 关系与重复说明**：复用七类关系及全树重复候选，将依据和疑似重复呈现为可检查说明；
  合并保留来源差异与限定，不静默删节点，不重新实现一套关系判断。
- **N7.4 格式边界**：继续交付 HTML、PNG、Markdown；支持离线阅读说明、键盘折叠和引用导航。
  本批不新增 XMind 等工程文件格式承诺。
- **工程验收**：所有节点与引用在完整大纲中保留，分支图有覆盖清单；标签不裁切、公式可读，
  不同条件/模型的近似节点不误合并；HTML/PNG/Markdown 使用同一文档版本，文件损坏按现有版本化机制修复。
- **人工验收**：概览能快速理解主题结构，展开后含义完整；常用屏幕或 A4 尺度下分支图可读，
  拆图后仍能理解主要跨分支关系。

### 13.4 三项 P1：上下文、整链回归和调用监控

#### N8 长对话与上下文边界（M）

- **N8.1 容量计量**：继续保守预算，在支持的模型/渠道上使用可靠的 tokenizer 或服务端计量校准估算；
  不支持时明确估算与余量。区分输入窗口、单次输出上限、推理用量和整轮累计用量，未知字段不补零或编造。
- **N8.2 压缩后的语义**：复用有来源的记忆，重点保留最新用户约束、改口、未决问题及原文锚点；
  历史结论仍作为背景，不能冒充本轮已核验证据。必要指令和最小证据容不下时明确结束，不静默截断后继续。
- **N8.3 压力与恢复**：受控 20/50/100 轮历史覆盖改口、跨主题、超大单轮、不同窗口和摘要后刷新恢复；
  所有摘要/重试仍计入现有调用预算，不自动重发未确认计费的上游调用。
- **工程验收**：关键约束保留、来源可追溯、错误旧结论不被继承、估算偏差可记录、超限终止有明确原因；
  同一请求的重试不得绕过调用上限；用户主动继续作为新请求受单次调用上限约束，继承已消耗的自动修订额度，
  不重复已封存阶段、不重发未确认计费的调用。人工对真实多轮语义和实际延迟作判断，固定历史不替代真实模型测量。

#### N9 登录态整链与界面回归（M）

- **N9.1 可重复场景**：复用现有组件和接口夹具，补浏览器中的上传/输入、配置、提交、流式显示、停止、
  显式继续、刷新恢复、引用定位、版本切换与下载；七类任务分别覆盖自己的主要输入和输出。
- **N9.2 身份与环境分层**：本地受控接口验证显示和故障分支；隔离/预发布环境以测试身份验证真实认证、
  数据库、文件和浏览器衔接。真实模型产物由用户线上触发检查，不能把模拟登录或模拟响应写成生产整链已验收。
- **N9.3 发布回归门**：保存桌面、手机、低高度窗口及明暗主题截图和命中检查；覆盖设置展开、长文本、
  错误提示、对话头像/图标、导图/表格滚动和引用弹层。重叠、溢出、键盘不可达及状态不一致作为失败。
- **工程验收**：对既往遮挡和图标缺失有可复现回归；身份切换不串数据，取消后不出现迟到写入，
  旧版本下载保持旧字节。浏览器测试按涉及页面和发布范围运行，不把全站外观重测作为每次小修改的前置。

#### N10 模型调用、计量与线上质量监控（M）

- **N10.1 关联与计数**：复用 request_id/trace 和已有指标，关联任务、阶段、角色、实际 HTTP 尝试及结果；
  分开统计生成、核验、修订、重试和恢复复用。流式事件数量不是模型调用次数，解析/导出重试也不能混算。
- **N10.2 面向用户的进度**：展示当前步骤、已发生调用、等待/重试原因、可用操作与终止原因；
  不展示伪造的思考过程，不把正在等待说成新一轮工作。默认用简明状态，详细诊断放可展开区域。
- **N10.3 计量与趋势**：记录实际可获得的输入、输出、推理 token 和计量缺失情况；费用只有在价格与计量可用时估算，
  并注明口径。按任务场景区分首次完成、恢复完成、待复核原因、延迟、排队及渲染异常，保留样本数量与时间范围。
- **N10.4 有界故障处理**：沿用已上线调用预算、超时和重复草稿检测；告警聚合相同原因，
  不为消除告警自动多次付费重跑。是否调整角色思考强度，由人工质量反馈和实际调用证据决定，不全局改成弱思考。
- **工程验收**：HTTP 重试、流断开、重复事件、取消、预算耗尽及恢复场景的调用数与请求记录一致；
  供应商未返回计量时显示未知；日志不含凭据或默认收集完整私人正文。监控界面有数据来源，不能用演示数据冒充线上统计。

- **验收**：N9 场景中没有覆盖、裁切或横向页面溢出；主操作能找到、状态能读全、键盘可达；

### 13.7 分层验收与停止条件

- **工程层**：结构、计算、引用绑定、版本一致性、调用/重试上限、取消恢复、真实文件渲染和浏览器操作。
  采用受影响测试与已有故障矩阵，新增契约检查针对用户结果，不以测试数量作为质量目标。
- **人工层**：由用户判断事实、比较、评审价值、统计解释、汇报节奏、导图组织及视觉可读性；
  可以逐场景验收，不要求一次完成全套。评价缺失时保持“工程完成 / 待人工验收”。
- **发布层**：记录明确的候选版本、包含和未包含的任务、实际依赖与资源限制、必要的备份/回滚及部署后检查；
  当前 1 GiB 约束下的新渲染能力需先做容量验证。方案完成不等于部署授权或上线完成。
- **失败处理**：错误证据、原文不存在的断言、方向/单位/公式错误、错误实验设计、跨用户/跨版本混用、
  核心文件打不开或关键内容被裁切，均不能被平均分或“其他检查通过”抵消。修复局部问题后保留原失败记录。
- **阶段退出**：达到现有调用/时间预算、材料不足、上游返回未知或能力不支持时，保留可用结果与清楚限制，
  不自动重放未知付费调用，不把一次渲染/核验失败升级为无限整稿重写。
