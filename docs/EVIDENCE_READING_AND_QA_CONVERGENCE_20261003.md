# 来源伴随阅读、核验说明与补读收敛

更新：2026-10-03。本批仍为本地工作，未推送、未部署。

## 来源面板

报告的证据侧栏与论文问答的依据选择使用独立的非模态阅读交互：不锁住正文滚动，不限制焦点只能留在侧栏，不添加模糊或暗色遮罩。宽屏为证据面板预留阅读空间；窄屏使用占部分高度的面板，正文仍可阅读和滚动。

关闭面板时，键盘焦点使用 `preventScroll` 回到引用；点击正文或其他操作关闭时保留当前交互位置，不再主动聚焦最初引用。正文文字选择期间保持面板打开，引用切换不会触发点击外部关闭；不同阅读面板间避免同时堆叠。

交互单元测试覆盖无滚动锁、正文操作可达、外部点击不恢复旧焦点、Escape 返回焦点且不触发滚动、来源切换及原有引用绑定。浏览器下的实际宽窄屏布局与滚动观感仍由用户手动验收，不能将 jsdom 交互测试称为真实浏览器验收。

## 核验说明

`consistency_verifier_failed:ValueError` 显示为“来源之间的一致性核对未完成。返回结果未能通过检查，请稍后重试。”，不再误导为来源已经存在争议或已经形成佐证。常见原文匹配、语义、数值及引用错误统一转换为可读说明；有意义的自然语言解释保留。

证据卡片、徽章提示、核验详情、打印内容及问答过程使用同一转换函数。机器诊断仍保存在原始记录中，未改写服务端判断。未知机器码使用与当前状态相符的说明，不直接展示内部变量名。

检查后台错误路径时同时发现，一致性核验捕获普通异常的分支也会吞掉执行租约丢失。现已让租约丢失直接向上退出；普通 `ValueError` 仍保留为未完成的核验状态，两个分支均有回归用例。

## 论文追问

sc63 曾再次选择已读章节，旧代码将空的新目标集合解释为全部剩余章节，扩大了付费读取。本批增加明确的定向补读、扩大读取和保留待确认项三种决策；重复目标会要求纠正计划，不能触发隐式全文读取。确需扩大范围时必须明确说明理由，未设置累计 token 预算。

补读后再次检查证据覆盖，即使已经读完可用材料也不直接认定问题全部得到回答。已查相关章节、没有必要的新目标时，回答已有依据的部分，并保留尚未确认的细节；已知存在其他图例数值时仍须补齐。待确认项随缓存保存，前端在回复旁明确显示，避免再次提问丢失不确定性。
